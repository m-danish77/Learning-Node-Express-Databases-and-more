## 📚 Curriculum Overview

This repository is organized into modules following the course structure:

### 🔹 Level 1: Node.js Fundamentals
*   **01 & 02:** First Node.js script & Creating a Node Server.
*   **08:** Parsing Requests using CommonJS Modules.
*   **09:** 🧮 **Calculator Project** (Pure Node.js).
*   **10 - 12:** Asynchronous Code, NPM Tools, and Debugging.

### 🔹 Level 2: Express.js Deep Dive
*   **13 - 14:** Introduction to Express & Practical Exercises.
*   **15 - 17:** Advanced Express concepts, Deep Dive Exercises, and Styling.
*   **18 - 19:** Dynamic UI rendering using **EJS (Embedded JavaScript)** templates.

### 🔹 Level 3: Architecture & Databases
*   **20 - 21:** 🏗️ **MVC Architecture** (Model-View-Controller) implementation.
*   **22 - 23:** Working with Dynamic Paths.
*   **24 - 26:** Database Integration:
    *   Storing data in **PostgreSQL**.
    *   Native **MongoDB** driver integration.
    *   Object Data Modeling with **Mongoose**.

### 🔹 Level 4: Advanced Concepts & Full Stack
*   **27 - 28:** Handling Cookies, Sessions, and User Authentication/Authorization.
*   **29:** File handling: Image Upload and Download functionality.
*   **30:** 🏁 **Final Project:** REST APIs & Full Stack ToDo List.

## 🚀 Getting Started

To run any project locally:

1.  **Clone the repository:**
    ```bash
    git clone [https://github.com/your-username/your-repo-name.git](https://github.com/your-username/your-repo-name.git)
    ```
2.  **Navigate to a specific folder:**
    ```bash
    cd "30 - Rest APIs and Full Stack ToDo List"
    ```
3.  **Install dependencies:**
    ```bash
    npm install
    ```
4.  **Start the server:**
    ```bash
    npm start
    ```
